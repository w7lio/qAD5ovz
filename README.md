### 3.Push
> [!WARNING]
> ```find -type f -size +100M -printf '%s bytes\t%p\n' | sort -nr```   
> ```git rm --cached "PATH"  ```

> **Push Folder**
```
git add abcxyz/
git commit -m "Upload Folder"
git push --force
```

> **Rename** 
```
git mv nameOld nameNew
git commit -m "Rename Folder"
git push --force
```

> [!TIP] 
> Sync Readme
```
git fetch origin `lấy thông tin phiên`
git restore --source=origin/main -- README.md *khôi phục về readme mặc định repo*
```
